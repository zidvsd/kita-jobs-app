## Contributing to KitaJobs

Thanks for your interest in contributing — we appreciate it!

This file contains a short, practical guide to get contributions in shape quickly.

How to contribute

1. Fork the repository and create a feature branch: `git checkout -b feat/short-description`.
2. Keep changes small and focused. Add tests where applicable.
3. Ensure TypeScript compiles and lint checks pass.
4. Open a pull request describing the change and why it helps. Link any issues if relevant.

Coding conventions

- Follow existing code style in `frontend/` and `backend/` (TypeScript, ESLint where configured).
- Run linters and formatters before committing.

Communication

- Open an issue for any non-trivial work or to propose large changes before implementation.
- Use PR descriptions for context and testing instructions.

Thank you — maintainers will review PRs as time permits.
